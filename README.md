# Alaska Adventures - Interactive 3D Map

## Week 6 - Assignment 5
Introduction to Web GIS

## Project Description
This project uses the ArcGIS Maps SDK for JavaScript
to create an interactive 3D map of Alaska.

The map highlights locations related to fishing,
camping, hiking, and outdoor exploration.

## Features
- Interactive 3D map with elevation
- Customized Alaska adventure locations
- Different marker colors for activities
- Popups with location descriptions
- Click-to-zoom camera navigation
- City search with predefined locations

## Map Locations
- Fairbanks
- Galbraith Lake
- Nome
- Minto
- Denali National Park
- Valdez
- Chena Hot Springs
- Delta Junction
